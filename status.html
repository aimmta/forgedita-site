Product status

Active beta, with the limits stated plainly.

ForgeDITA is in active beta. Review completed foundations, current evaluation work, limitations, and the boundary between beta and general availability.

ForgeDITA has completed its MVP and release-candidate gates and has progressed through core API, web UI, deployment, import, conformance-publication, and editor-integration work. It is now in active beta for controlled evaluation.

Available in beta

  • Native XML repository and revision operations
  • Repository, content, baseline, release, workflow, and package APIs
  • Graph extraction, map context, resolution, and impact views
  • Layered validation with tenant toolchain assets
  • Queued preview and publish with manifests and governed artifacts
  • Search, bulk import, web administration, and Oxygen integration packages

Current beta work

  • Production Oxygen task-by-task acceptance
  • Deeper DITA scope, filtering, subject-scheme, and specialization coverage
  • Representative-corpus scale and relevance testing
  • Hosted identity-provider and deployment evidence
  • Broader migration and cloud-provider fixtures
Beta is not general availability. ForgeDITA does not claim universal DITA 1.3 support, DITA 2.0 support, independent security certification, or complete contextual resolution for every specialization and profile combination.
